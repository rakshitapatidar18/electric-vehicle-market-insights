Solution Architecture

Engineered with modular Python pipelines, SQLite relational storage, and interactive visualization layers.

⚡ Data Pipeline: Raw CSVs (300k rows) → Deduplication & Domain Median Imputation → Cleaned Dataset

🗄️ Database: Normalized SQLite 3NF Schema (6 tables, 10 indexes, 0 FK errors)

📊 Analytics Engine: Reusable Pandas routines with 100% KPI parity with SQL

🌐 Web Application: Responsive Flask framework with interactive Plotly visual charts

📈 Business Intelligence: Tableau Public export pipeline with enriched calculated dimensions

About the Project

Academic & technical overview of the Electric Vehicle Market Performance & Insights analytics solution.

Project Overview

B.Tech Artificial Intelligence and Data Science Individual Capstone Portfolio Project.

Objective: To engineer an end-to-end business intelligence and data analytics solution that evaluates the global electric vehicle market across manufacturer competitiveness, battery chemistry performance, driving range trade-offs, pricing dynamics, and geographical assembly hubs.

Dataset Integrity: The solution processes 299,999 distinct vehicle records spanning 200 global automakers, 15 vehicle categories, and 5 battery chemistries across model years 2018 to 2026.

Academic Scope: Pure data analytics, relational SQL modeling, statistical profiling, and business intelligence dashboarding. No machine learning models are trained; real empirical metrics and domain median imputations govern the analytics pipeline.

Technology Stack

Modern open-source data engineering and web technologies.

  • Programming Language: Python 3.14+
  • Data Processing & Analysis: Pandas & NumPy
  • Relational Database: SQLite 3 (3NF Normalized)
  • Interactive Visualization: Plotly & Tableau Public
  • Web Application Backend: Flask 3.1+
  • Automated Testing: Pytest
  • Version Control: Git & GitHub
